# Hearts2Hearts 梦女模拟器（重制版）

一个可直接在浏览器打开的单文件偶像恋爱模拟小游戏。内置 Hearts2Hearts 8 位成员，支持与 AI 角色用 KakaoTalk 风格私聊、接收 Bubble 1:1 订阅消息、查看 Instagram 动态和日历，到点还能打开「赴约」App 进入线下见面演绎，并会随着对话累积好感度。三个 App 都按现实中的原型复刻：私聊是 KakaoTalk，订阅消息是 Dear U Bubble，动态是 Instagram；日历则把约会、日程和共同记忆摊开。玩家固定为女性；8 位成员都是女同性恋，这段关系是女性之间的秘密恋爱，没有异性恋叙事，也不做「掰弯」设定。

> Hearts2Hearts 实际是 8 人组合（JIWOO、CARMEN、YUHA、STELLA、JUUN、A-NA、IAN、YEON），所以这里做齐了 8 位。

## 打开方式

- 直接双击 `index.html`，用 Chrome / Edge 打开即可（`file://` 下可正常运行）。
- 或在本目录启动一个本地服务器：

  ```bash
  python -m http.server 8080
  ```

  然后访问 `http://localhost:8080/index.html`。

## 配置 AI（必需）

对话、Bubble 和 Instagram 都由你自己的 AI 接口生成，第一次进入请先到「设置」填写。游戏兼容任何 OpenAI 格式的 `/chat/completions` 接口：

| 字段 | 说明 |
| --- | --- |
| API Key | 你的密钥，仅保存在本机 `localStorage` |
| 接口地址 | 可填 `https://api.openai.com/v1`、`https://api.deepseek.com` 这类根地址，也可直接填完整的 `.../chat/completions` |
| 模型 | 如 `gpt-4o-mini`、`deepseek-chat` 等 |

没有填写 Key 时，主页会显示提示条；点「发送」会先弹提示并跳回设置页，不会把消息发进聊天记录。

第一次进入会自动打开 17 步图文教程（主页新增了「教程」App，开始页和设置里也都能随时重看），里面用模拟界面讲清楚：女性/地下关系设定、开局选人与称呼/人设补充、八位成员不同的推进节奏、申请 Key、地址和模型、测试连接、8 个 App 的分工、KakaoTalk 私聊（已读/输入中/事件卡/冷战）、Bubble 单向订阅、Instagram 自动动态与女友视角、叙事日与现实钟点/日历、「赴约」线下演绎、豆瓣三个小组、队友私信、状态/风险/暗号/分层记忆/场景与记忆冲突、每日结算、事件、决定之夜结局与多周目、风险记录与三档风险事件、「本局花费」、存档/隐私。设置里的「测试连接」会发一条很小的请求，成功显示绿色耗时/模型，失败会提示 Key、地址、模型名或跨域问题。

## 发布给粉丝前的准备

- **图文教程在游戏本体里**：不依赖外部文档或单独页面，主页有独立的「教程」App，开始页、设置页也都能打开。
- **连接测试**：避免粉丝以为游戏坏了，其实是 Key / 地址 / 模型没填对。
- **多存档 + 导出导入**：设置里 3 个手动槽位，可保存 / 读取 / 删除；也能把当前进度导出为 JSON，换设备用「导入存档」继续。自动存档仍然照常进行。
- **发送失败重试**：私聊 / 私信回复失败时，消息不会消失，输入框上方会出现「重试」条，点一下用同一段上下文重发。
- **隐私说明**：Key、聊天和存档都只在本机浏览器里，没有账号、没有云端同步；界面内明确提示不要把 Key 发出去。
- **按键音效**：按钮点击与键盘输入有轻音效，设置里可随时关闭；默认开启。
- **背景音乐（外部文件 / 多首播放列表）**：音乐不写进代码。把 `bgm.mp3` 放进 `h2h/music/` 是单曲循环；想放多首，就按顺序命名 `bgm1.mp3`、`bgm2.mp3`、`bgm3.mp3`…最多 20 首，游戏会自动识别连续序号并依次播放，播完最后一首回到第一首。多首时不要同时保留 `bgm.mp3` 和 `bgm1.mp3`；两者都在会从 `bgm1.mp3` 开始，`bgm.mp3` 不进入列表。也兼容直接放在 `h2h/` 根目录；单曲还支持 `.m4a` / `.ogg` / `.wav` / `.flac`。设置 →「聊天外观 & 声音」有背景音乐开关、音乐音量滑条、上一首/下一首按钮，音量会记住。浏览器不能扫描文件夹里的任意文件名，所以多首必须用连续序号；没有音乐时设置页会明确提示，不会报错或假装在播。浏览器若禁止无点击自动出声，点一下页面即可开始。

## 玩法与功能

- **8 位成员设定（已按文档融合）**：每位成员都补入了身高与关系原型（年上掌控型 / 安稳型 / 甜蜜暴君型 / 甜蜜直球浪漫型 / 直球细腻年下型 / 热情冲动年下型 / 外热内冷型 / 年下腹黑冷静型），以及饮食、音乐、游戏、动物、季节等生活细节；但设定只作为背景，AI 不会每条消息都拿出来强调，也会无聊、跑题、沉默或已读不回。叙述里统一用「中文名（英文艺名）」，例如「崔志宇（JIWOO）」「柳河览（YUHA）」；玩家固定为女性，成员为女同性恋，提示词明确禁止男性代词、异性恋叙事和「例外 / 被掰弯」写法。角色设定面板只向玩家展示「基础档案」，更细的性格与雷区只用于 AI 扮演，不会剧透给玩家。
- **会自己走的世界**：故事从第 1 天开始，有时间（深夜 / 清晨 / 上午 / 中午 / 下午 / 傍晚 / 晚上）、叙事日期（几月几日、星期几，按叙事天数推进）和随机行程（打歌、练习、录音、电台、签售、综艺、团综、拍摄、演出、海外、校庆、公益等 20 多种）。没有固定星期几的排班，也不会把周日写成休息日；有些天完全没有公开行程。现实时钟只负责气泡下的 `HH:MM` 和 Bubble 营业时间；消息日期分隔、Instagram 时间、Bubble 订阅天数、日历、约会、冷战、特殊日子和节奏全部用叙事日历，不会再出现私聊里是叙事 14 号、日期条却是现实 13 号的情况。每天是否有行程、每月休息几天都不固定，不是排班表；AI 会读到未来 8 天的日历，问「下次签售/见面会是什么时候」会按日历回答，不会说「不知道，等公司安排」。主页小组件下方有「结束今天」按钮，点一次把故事推进一天，不会卡结局；她的生日、出道纪念日和第 100 天会主动发消息。首页状态、抽屉和所有 AI 提示词都会带上当前叙事日期、时段与行程；问「明天/后天」时按叙事日历回答，不会被现实日期带偏。
- **公开世界会注意到你们**：曝光风险到 40 / 60 / 80 时，会依次出现「工作人员注意到」「经纪人约谈」「私生跟拍」这类记录，粉丝社区也会分阶段开始讨论——从「有人注意到互动」到论坛猜测帖，再到 Dispatch 跟线。反应会出现在 Instagram Activity 的「公共讨论」里，也会变成最新动态下的粉丝评论，她本人则会发消息提醒你最近小心。
- **共同记忆（结构化 + 分层）**：每条记忆都有类型（暗号/约定/关系/见面/风险/关于你/偏好/节点/日常）、重要度、来源、日期、标签和使用次数；只记录真的发生过、值得记住的事——约定、约会、暗号、冷战、风险事件、成员介入，以及你告诉过她的重要个人信息。日常寒暄不会写进来。抽屉里能看到最近 12 件，按「重要 > 重要度 > 日期」排序并显示类型。注入提示词时不再倒序塞最近几条，而是分层：核心记忆（暗号/约定/手动标记重要）、最近几天、和这次聊天相关、长期印象；会按当前聊天内容做关键词相关性回引，并控制长度，避免越聊越糊。
- **她此刻的场景**：抽屉顶部新增「她此刻」，按当前时段、她今天的行程、正式/临时约会推导地点和正在做的事，并标明你是否在她面前。这个场景会写进私聊、Bubble 和队友私信提示词，避免她一边说在练习、一边说就在你旁边；她也可以用隐藏的 `[SCENE:地点|正在做的事]` 更新场景，标签不会显示在气泡里。聊天里已经明确说「到了/到宿舍了/到公司了」时，即使模型忘了标签，游戏也会从当前路线推断目的地并更新场景，不再停在「回宿舍的路上」。
- **跨 App 行程一致**：KakaoTalk、Bubble、Instagram 和日历共用同一份未来行程；Bubble/IG 的提示词也会读未来 3 天日历，不会出现日历写着明天校庆、Bubble 却说「明天没行程」。
- **聊天里定下的见面会进赴约**：不一定是正式约会；只要聊天里明确说「明天校庆见/明天来学校见」且没有拒绝，游戏会把这次线下见面记进赴约 App，显示日期和地点，并在顶部弹出「赴约已记录」。
- **属性增减提示**：好感、信任、吃醋、风险变化时，顶部会短暂出现「好感 +1 · 信任 +1」这类小提示；拒绝赴约、取消约会、事件结算和见面结算也会显示对应变化。
- **记忆冲突检查**：称呼、阶段、暗号、最近见面和当前场景被当成固定事实。她如果改暗号、在初识阶段叫「老婆/宝宝」、把没发生的事说成发生、在错误时段说早安/午安/晚安，或说到未来的天数，游戏会先带纠正重试；仍冲突就删掉冲突句，不让错误事实进入下一轮记忆。
- **每日结算**：主页「结束今天」或自然跨日时，会统计当天的私聊、回复、Bubble、约会和事件。有联系会加信任；约会和聊得多会加好感；一整天没联系会掉好感和信任，冷战还会再掉信任；吃醋和风险缓慢回落。结算生成一条日常记忆，并弹窗显示当天数值前后变化；如果新一天同时有事件弹窗，结算会排队，等事件关掉后再出现。
- **她会主动找你**：挂着页面时，她可能突然发来私聊，Bubble 也会按营业时间不定时出现新消息；未读会汇总成首页通知卡片（保留最近 5 条，可一键清除），点一下直接跳进对应 App。浏览器标题会显示未读总数；设置里可以开启系统通知，页面在后台时会弹出浏览器通知。系统通知需要浏览器支持且处于安全上下文：部分手机自带浏览器、直接用聊天软件打开本地文件时可能不可用；不支持时设置里会直接禁用并说明替代方式（iPhone 添加到主屏幕后用 Safari、Android 用 Chrome），首页通知卡片始终可用。
- **离线追赶**：关掉页面再回来，如果离开了 25 分钟以上，她会把这期间发过的 1–3 条消息补给你，按时间显示成未读（需要已配置 API Key）。世界不会因为你离开就停在原地。
- **已读不回会被记住**：你读了她最后一条消息却没有回，过几分钟她可能会补一句「已读不回」，吃醋值上升、信任度下降；这不是提示，是她真的注意到了。吃醋值很高时，她可能不只是补一句，而是直接进入冷战。
- **冷战与修复（没有提示条）**：已读不回、吃醋或高风险事件可能让她真的冷下来——她回复变短、避开暧昧的话、不再发 Bubble。游戏不会弹「哄她」按钮，也不会告诉你她在生气；你要从聊天里自己看出来，再用一句真心的解释、道歉或关心把她拉回来。拖太久（4 天以上）还有概率走向「无疾而终」。
- **队友私信（成员/经纪人施压）**：世界不是只有粉丝。每位成员都有 2 个专属施压事件：柳河览（YUHA）会来提醒你别让崔志宇（JIWOO）为难，金多绚（STELLA）会护着卡门（CARMEN），郑伊安（IAN）会把柳河览（YUHA）的反常告诉你，经纪人也可能用小号找你。这些内容现在统一走 KakaoTalk 顶栏的「队友私信」独立会话，不再单独弹窗；你可以坦白、请对方保密、或把话推回去，回答会被记住，并影响信任、风险、吃醋和后续公共讨论。
- **约会系统（约在聊天里，见在「赴约」里）**：关系过了「初识」后，她会在私聊里直接问「周六晚上要不要去汉江边」，你像正常聊天一样回她；你也可以主动约她，看她答不答应。约好后日历里会出现这一天，首页会提前提醒；到了那天 App 会亮红点，打开「赴约」进入线下演绎：牵手、保持距离、说什么，都在见面现场发生，不再弹选项框，也不用在 KakaoTalk 里打「我到了」。临时见面（她叫你过去拿东西、楼下见一面）也会通知你，打开赴约就能直接进。放鸽子会掉好感，也会留下记忆。
- **赴约 App**：首页第 7 个 App，粉色渐变图标。约会到点或她临时叫你过去时会亮红点；正式见面采用标准演绎模式：她的每次回复都是「现场叙述 + 动作/神态/环境 + 引号对白」，不会只回一句聊天台词，也不是聊天气泡；你自己输入要说什么、做什么，一轮一轮往下演；结束见面时按你有没有靠近结算好感、信任和曝光风险，并把这次见面写进共同记忆和约会记录。每次结束都会保留当天的完整演绎记录，之后在「见过之后」里点开就能重看，只能看、不能继续操作。见完她不会一直停在原地：临时见面超过一小时就过期，她会回去；正式演绎如果超过 3 小时没有互动（比如中途关了页面），会按「没有好好告别」自动收尾，保留已有记录并清掉红点，不会永远卡在「待回复」。曝光风险过高时，她可能主动取消已经约好的正式约会，并在私聊里解释。
- **结构化事件引擎**：内置 48+ 个事件，覆盖日常、关系、行程、粉圈、公司、现实、圈内、危机八类；每次事件都是私聊里的一张内联事件卡，不再弹单独的选项框。**危机、公司、粉圈这三类大事件出现时，底部输入框会暂时隐藏，必须先选一个选项；日常、关系、行程、现实、圈内事件则可以边聊边点，选完不会追加线下台词，结果直接记进数值和记忆。** 卡里会写清前因，3 个选择各自影响至少两项数值（好感/信任/吃醋/曝光风险/心情）；事件会进入共同记忆并进入冷却。事件由当前叙事日、时段、关系阶段、行程密度、曝光风险、吃醋和最近一次事件类型共同加权抽取，不是每天固定抽同一类；**开局第 1 天不会立刻弹事件，至少进入第 2 天、且有过 2 轮对话后才可能触发**；危机类只在风险足够高时出现。旧的聊天风险事件和弹窗介入已经并入同一套：风险事件改由危机/公司/粉圈事件卡处理，成员和经纪人的压力统一走队友私信，不再同时运行两套系统。

- **多种结局与周目**：不再用天数卡结局。好感/信任跌到极低且已经相处过一段时间会走向「无疾而终」；曝光风险到 90 会走向「曝光」；关系走到恋人、数值足够高后，「角色属性」里的按钮不再是一张三选一菜单，而是一场「决定之夜」：她把你约到汉江边，当面问「如果有一天真的藏不住了，你会怎么选」，你自由回答公开、继续藏或退一步，结局由回答加上当下数值共同决定（公开的恋人 / 地下恋人 / 曝光 / 无疾而终），之后还有公司声明、队友私信和豆瓣新帖等后果跟着发生。曝光风险到 90 时按信任分流：信任足够就提前进入这一晚，把决定权交给你；信任不够才是被动曝光。结局弹窗里可以「开始新周目」：重新回到第 1 天，但会保留上一周目的结局记忆、最多 8 件「前世的残影」、你们的暗号、8 条约会记录和更高的初始好感/信任；抽屉里会显示当前周目和继承件数，AI 提示词会加入「周目记忆」，让她隐约觉得这一刻似曾相识，但不会直接剧透上一世。
- **当前状态面板**：抽屉中展示「初识 → 熟人 → 暧昧 → 恋人」阶段阶梯、好感度 / 信任度 / 吃醋值三条数值条、当前心情、关系温度、当前日期与时间、曝光风险、你们的暗号、下一次约会或冷战状态、按重要度和相关性分层注入的共同记忆、距离下一阶段还差多少，以及当前关系的一句提示；雷达图用原生 Canvas 绘制，不再依赖外部 CDN；设备绘制失败时自动降级为文字数值。日历 App 则负责把约会、日程和特殊日子摊开给你看。
- **流式输出**：设置里默认开启，AI 回复会像真的在打字一样一个字一个字出现；接口不支持流式时会自动退回普通请求，不会把消息卡住。可随时关闭。
- **聊天主题**：设置里可切换 KakaoTalk 的经典浅蓝 / 深色主题，只影响私聊界面。
- **四维数值**：好感度 A、信任 T、吃醋 J、心情 M；阶段从「初识 → 熟人 → 暧昧 → 恋人」自动推进，达到恋人时触发关系节点提示；真正会结束故事的结局见上文。新开局为好感 10 / 信任 5；提示词里有数值硬约束：低好感时她不会主动买吃的、关心你、打情骂俏或约你，违反当前数值的对话会被判定为出戏。八位成员都是女爱豆，任何阶段都不能暴露恋情。
- **关系雷达图**：抽屉中查看（Chart.js 加载失败时自动降级为文字条形图）。
- **存档**：自动保存到 `localStorage`（键名 `h2h_save_v2`），存档版本为 3，刷新后回到上次界面；写入做 300ms 防抖，切后台/关页面时强制落盘。每次写主存档前会自动保留 `h2h_save_v2__bak`，主档损坏时从备份恢复并提示。旧版 v2 存档读取时会自动迁移：补齐字段、把内嵌的 data URL 图片搬进 IndexedDB、存档只留 `idb:` 引用，再写回 v3。设置里另有 3 个手动槽位和 JSON 导出/导入，可备份、换设备或删档；导出会自动把图片还原成 data URL，导入会重新写回 IndexedDB。可在设置里重置存档或重新开始故事。旧存档会按成员 id 自动套用新版性格设定。

## 自动化冒烟测试

目录里带一套 Playwright 测试，防止顶栏偏移、豆瓣假数据、事件串线、图片存储和存档恢复这类问题回归。需要本机安装 Chrome。

```bash
cd h2h
npm install
npm test
```

`npm test` 会启动本地静态服务器（4173），用 `?smoke=1` 打开游戏并跑 20 个用例：

- 所有 App 的顶栏标题居中（逐屏量中心点，容差 1.5px）；
- 无 Key 时豆瓣不展示本地假帖，只显示错误和重试；
- 无 Key 时私聊 / Bubble / Instagram 显示配置提示，不塞本地队友动态、红点或通知；
- 对话风格检测能识别碎片/逗号结尾，并保留 `[STATUS]` 标签；
- 有 Key 时队友 Instagram 由 AI 生成，评论区不用本地模板；
- 聊天 AI 回复里的 `[STATUS]` 会被解析，不会漏到气泡里；
- 非锁定事件不追加聊天、不推 setup，锁定事件才追加；
- 上传图片后存档只留 `idb:` 引用，刷新后仍显示，导出 JSON 含 data URL；
- v2 旧存档自动迁移到 v3，内嵌图片搬进 IndexedDB；
- 主存档损坏时从 `__bak` 自动恢复；
- 读取存档槽后回到首页，不会停在设置页；
- 背景音乐音量滑条存在，调节后写入 `localStorage`；
- 场景状态给出地点/活动，抽屉显示「她此刻」；
- 记忆冲突检查识别错误暗号与越界阶段，正确暗号不误报；
- 每日结算记录当天计数、数值变化和结算记忆；
- 只有事件、没有私聊的日子也算联系，结算会显示事件次数而不是「几乎没有联系」；
- Bubble 提示词包含未来日历，不会把明天的行程说成没行程；
- 聊天里说「到了/到宿舍了」会更新她此刻的地点；
- 聊天里约定「明天校庆见」会生成赴约记录，并在顶部提示；
- 好感/信任变化时顶部会出现属性增减提示。

测试产物（`test-results/`）和 `node_modules/` 不需要发布；发布时保留 `index.html`、`README.md`、`package.json`、测试文件和 `music/` 文件夹即可，也可以只发 `index.html`（但没有 `music/` 就没有背景音乐，设置页会提示找不到文件）。
